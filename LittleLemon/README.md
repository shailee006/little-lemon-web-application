# Little Lemon API project

A Django REST Framework API for the Little Lemon peer-graded assignment.

## Setup (Python 3.11 recommended)

```bash
cd LittleLemon
pip install pipenv
pipenv install
pipenv run python manage.py migrate
pipenv run python manage.py seed_demo
pipenv run python manage.py runserver
```

Open:
- Django admin: http://127.0.0.1:8000/admin/
- API root: http://127.0.0.1:8000/api/
- Djoser user creation: POST http://127.0.0.1:8000/auth/users/
- Token login: POST http://127.0.0.1:8000/auth/token/login/
- Token logout: POST http://127.0.0.1:8000/auth/token/logout/

Authentication uses `Authorization: Token <token>`.

## API endpoints

| Requirement | Endpoint | Method |
|---|---|---|
| Categories | `/api/categories/` | GET; admin POST |
| Menu items | `/api/menu-items/` | GET; admin POST |
| Filter category | `/api/menu-items/?category=1` | GET |
| Featured items | `/api/menu-items/?featured=true` | GET |
| Sort by price | `/api/menu-items/?ordering=price` | GET |
| Pagination | `/api/menu-items/?page=2` | GET |
| Manager group | `/api/groups/manager/users` | GET/POST/DELETE |
| Delivery crew group | `/api/groups/delivery-crew/users` | GET/POST/DELETE |
| Cart | `/api/cart/menu-items` | GET/POST/DELETE |
| Orders | `/api/orders` | GET/POST |
| Assign order / update status | `/api/orders/<id>` | PATCH |
| Delete order | `/api/orders/<id>` | DELETE |

POST `/api/cart/menu-items` JSON: `{"menuitem": 1, "quantity": 2}`.
POST `/api/orders` creates an order from the authenticated user's cart.
PATCH `/api/orders/1` manager JSON: `{"delivery_crew": 3}`.
PATCH `/api/orders/1` delivery crew JSON: `{"status": true}`.

## Notes

`Pipfile.lock` is generated by Pipenv during dependency installation if it is not present in the archive. A `requirements.txt` is also provided as a fallback.

- Demo users and sample menu data are created by `seed_demo`.
- The included `db.sqlite3` is initialized on first `migrate`; always run migrations before testing.
- Review permissions and response codes in a local test environment before submission.
- For production, replace the development secret, disable DEBUG, restrict ALLOWED_HOSTS, and use secure credential management.


## Run the automated tests

After installing dependencies and applying migrations:

```bash
pipenv run python manage.py test LittleLemonAPI
```

The test suite checks public menu/category access, pagination, role permissions, featured-item updates,
manager assignment, cart operations, order creation, delivery assignment, and delivery status updates.

## Important submission checks

1. Run migrations before using the API: `pipenv run python manage.py migrate`.
2. Create sample accounts and records: `pipenv run python manage.py seed_demo`.
3. Run the test suite and resolve any local environment/database errors.
4. Verify the API manually in the browser or Insomnia using the endpoints in this README.
5. Keep demo credentials in `notes.txt` private to your course submission.
